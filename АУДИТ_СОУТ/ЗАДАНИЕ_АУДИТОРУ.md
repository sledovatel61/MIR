## 4. Формат отчёта

Составь короткий отчёт в файл `00_АУДИТ_СОУТ/ОТЧЁТ_АУДИТА_<имя_агента>.md` в той же ветке, где:
1. **Вердикт**: одобрено / требует правок / критические ошибки.
2. **Список замечаний** с указанием:
   - № пункта по таблице;
   - конкретная ошибка/несоответствие;
   - рекомендация, как исправить.
3. **Замечания по качеству описаний** (если что-то выглядит неправдоподобно, не соответствует отрасли/профессии);
4. **Пропуски** (если какая-то графа не заполнена).

Цель: чтобы после исправления замечаний документ можно было передавать в ООО «МИР» как черновик для редактирования по факту.
